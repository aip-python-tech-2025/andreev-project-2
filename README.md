## Возможности бота

* Создать заявку
* Открыть заявку
  * Обработать заявку
* Закрыть заявку

Сбор донатов:

1. На карту: 4200 0000 0000 0000
2. По СБП: +7 (921) 000-00-00
3. BTC: 0x000000000000000000000000000
4. USDT: 0x000000000000000000000000000

### Список команд

|     Команда      |              Описание |
|:----------------:|----------------------:|
|     `/start`     |        Запускает бота |
|     `/help`      |        Помощь по боту |
|  `/add_request`  |  Создаёт новую заявку |
